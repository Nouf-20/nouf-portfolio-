03. Projects

Cybersecurity Lab

ARP Poisoning & MITM Attack Analysis

A project exploring how ARP poisoning affects local network communication and enables Man-in-the-Middle attacks, carried out in an isolated lab environment using Kali Linux as the analyst machine and Metasploitable 2 as the target, via VirtualBox.

  • Analyzed the network and ARP table before the attack
  • Executed an ARP Poisoning attack using arpspoof
  • Intercepted and analyzed traffic with Wireshark
  • Applied defense mechanisms: static ARP entries, Dynamic ARP Inspection, network monitoring, and enabling HTTPS/SSH
  • Restored the network to its normal state after testing
